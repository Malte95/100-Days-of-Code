# 100-Days-of-Code

# 💯 100 Days of Code Challenge

I am taking part in the #100DaysOfCode challenge, where I commit to coding for at least 1 hour every day for 100 days.

This repository documents my daily progress, projects, and what I learn along the way.

---

## 🎯 Goals

* Build a consistent coding habit
* Learn and improve my programming skills
* Work on real projects
* Document my learning journey
* Build a strong GitHub portfolio

---

## 📁 Repository Structure

* `day-xx/notes.md` → Detailed notes and learnings
* `day-xx/code/` → Code and small projects
