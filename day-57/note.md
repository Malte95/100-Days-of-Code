# Project Completion: Aircraft Route Planner & Arduino Landing Gear Control System

Today I completed the final release and presentation phase of two aviation-focused software and embedded systems projects: the **Aircraft Route Planner** and the **Arduino Landing Gear Control System**.

Both projects are now fully implemented, tested, documented, and prepared for inclusion in my engineering portfolio.

## Aircraft Route Planner

The Aircraft Route Planner is a Python desktop application that models Airbus production and engineering sites as a graph network. It allows users to calculate and visualize optimal transport routes between locations.

Key features include:

* Airbus production network with multiple locations
* Breadth-First Search for route availability checks
* Dijkstra’s Algorithm for shortest-path calculation
* Route reconstruction and total distance calculation
* Error handling for unreachable destinations
* Tkinter-based graphical user interface
* Dynamic creation of locations and transport connections
* Executable desktop application

This project strengthened my skills in Python, object-oriented programming, graph data structures, pathfinding algorithms, GUI development, and software project organization.
