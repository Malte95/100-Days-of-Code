## What I did today

Today I developed a small **C# console game** where the player can collect and use resources.

I implemented the following features:

* Created a **while loop** so the game keeps running until the player quits.
* Added a simple **menu with user input**.
* Added a **wood resource variable**.
* The player can choose option `1` to **collect wood**.
* With option `2`, the player can **build a house**.
* Building a house costs **3 wood**.
* The game checks whether the player has enough wood before building.
* If there is not enough wood, the player gets a message.
* Option `3` allows the player to **quit the game**.
* Invalid inputs are handled with an error message.

### What I practiced

* `while` loops
* `if / else if / else`
* Variables and basic calculations
* User input with `Console.ReadLine()`
* Console output with `Console.WriteLine()`
* Basic game logic and resource management
